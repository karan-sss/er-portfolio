Featured project

project-infra: a production platform for about €7 a month

The self-hosted platform this site runs on, built from an empty cloud account with everything as code.

  • Terraform runs only in GitHub Actions. A plan guard prices every change against Hetzner's live API and blocks accidental server replacement.
  • No public SSH: admin and CI access go over Tailscale, and the origin firewall only accepts traffic from Cloudflare.
  • Images are built natively for ARM64, signed with cosign, scanned with Trivy and verified before deploy.
  • Encrypted restic backups to R2 with an automated monthly restore drill.

About this site

This page is a static site in an unprivileged nginx container on a 4 GB ARM64 server. A push to main builds it in GitHub Actions, signs it, and deploys it over the tailnet, without any PaaS.
